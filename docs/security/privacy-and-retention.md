# Privacy and Retention

Collect only data needed by the product. Restrict access by role and resource scope. Minimize personal information in logs.

Retention must be configurable by record type and jurisdiction. Legal, accounting, contractual and audit retention requirements take precedence over generic deletion.

Exports use the same authorization model as normal application access.

External AI must not receive personal, legal or financial data unless organization policy explicitly permits it. Sensitive prompts/responses are not logged by default.
